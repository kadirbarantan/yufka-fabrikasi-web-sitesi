# Çavuşoğlu Yufka Web Sitesi

Bu proje, Çavuşoğlu Yufka fabrikası için hazırlanmış kurumsal bir web sitesidir. Site, firmanın ürünlerini tanıtmak, üretim sürecini anlatmak, yufka ile yapılabilecek tarifleri sunmak ve toptan/bayilik başvurularını almak amacıyla tasarlanmıştır.

## Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript (Vanilla)
* Tailwind CSS (CDN üzerinden)
* Google Fonts (Inter)

## Kurulum ve Çalıştırma

Bu proje tamamen statik dosyalardan (HTML, CSS, JS) oluştuğu için karmaşık bir sunucu kurulumu veya paket yükleme (npm install vb.) işlemi gerektirmez.

1. Proje dosyalarını bilgisayarınıza indirin veya git üzerinden klonlayın.
2. Proje klasörünü açın.
3. `index.html` dosyasını tercih ettiğiniz bir web tarayıcısında (Chrome, Firefox, Safari vb.) çift tıklayarak açmanız yeterlidir.

Not: Geliştirme aşamasında yapacağınız değişiklikleri anlık olarak görmek isterseniz, VS Code editöründe "Live Server" eklentisini kullanabilirsiniz.

## Dosya Yapısı

* index.html: Sitenin ana sayfası.
* tarifler.html: Yemek tariflerinin detaylı olarak yer aldığı alt sayfa.
* style.css: Özel CSS stilleri ve animasyonlar.
* script.js: Mobil menü ve sayfa içi etkileşim fonksiyonları.
* /assets: Görseller, ikonlar ve logoların bulunduğu klasör.
* sitemap.xml ve robots.txt: Arama motoru optimizasyonu (SEO) dosyaları.
